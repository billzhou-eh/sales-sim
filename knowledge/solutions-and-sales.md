## The digital handover package (every Solutions delivery)
Engineering (CEP) → Netilion account setup → Digital commissioning (incl. SAT/IQ/OQ, calibration, visual checks) → Documentation (SDOC) → Operation (Netilion-powered: real-time condition + Heartbeat diagnostics + condition-based replacement recommendations). Transforms "hardware + project" into "hardware + project + ongoing IIoT value stream."

## How DS is sold
- **Three layers:** Sales Centers (SCs) own the customer; SBC Hubs accelerate "white spot" gaps; SBC Central + Product Centers provide portfolio/roadmap.
- **Customer digitalization journey (IBA entry model):** Transparency → Documentation → Troubleshooting → Process Monitoring → Automation → Remote Support. **DIBA/IBA is the opening move** — populate Netilion via DCS or FieldCare export without disrupting the customer.
- **Account targeting:** TAM2 (in BAP) is the data reference. Industry diversification goal: 5 industries above 10% of NS (currently ~4; O&G over-concentrated; growth wanted in Chemical, Power, F&B, Water, Life Sciences).
- **Anchor products to start a DS relationship:** **Field Xpert + Netilion Health.** Account scoring heuristic: installed base (1–3) × pain (1–3) × digital maturity (1–3); start with accounts scoring 7–9.

## Sales frameworks
- **Richardson Consultative Selling:** Prepare → Connect → Understand → Recommend → Commit → Act.
- **OSE (Outcome Selling):** lead with the customer outcome, then the technology.
- **SPIN + Sandler pain funnel** (what this simulator trains): Situation → Problem → Implication → Need-Payoff; uncover latent pain before pitching.
- **Value Anchor adoption loop:** purchase → value anchor → consumption gap → optimize → expand.
